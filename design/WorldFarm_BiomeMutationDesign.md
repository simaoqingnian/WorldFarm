# WorldFarm 地貌、适应系数与变异系统设计

## 1. 设计结论

当前建议采用“地貌区域 + 标准地块槽”的混合方案：

- 地貌在界面上是不规则区域，承担国家地图表现和地域氛围。
- 种植交互使用标准地块槽，承担点击、倒计时、收获、数值结算。
- 一个地貌区域不是一块地，而是一个可扩建容器，里面有 2-8 个地块槽。
- 作物不再被地貌硬性禁止，而是用适应系数决定产量、品质、成长时间和变异概率。
- 低适应种植大概率低产，小概率发现变异；这种“逆境试种”是中后期可玩性的核心来源。
- 具名地貌不是作物禁区，而是“基础地貌 + 环境属性 + 风土词缀 + 名产共鸣”的组合。
- 变异先走通用地貌模板，后续再为水稻、白菜、茶叶、玉米等重点作物追加特殊变异线。
- 稳定变异品种默认不再自然变异，后续成长通过育种系统组合性状，而不是普通种植无限套娃。

这个方案能同时满足三个目标：

- 地图有地域特色，不是纯格子农场。
- 种植交互稳定，不被复杂不规则点击区域拖累。
- 数值有探索空间，玩家愿意尝试“不合适”的组合。

## 2. 地貌和地块的关系

### 2.1 不推荐的方案

方案 A：每个地貌只有一块地。

问题：

- 决策太少，玩家进入一个地貌后只能种一种作物。
- 不利于订单并行、批量种植、试验变异。
- 地貌解锁后很快被消耗完新鲜感。

方案 B：完全不规则大小地块，玩家直接在任意形状区域里种。

问题：

- 手机触控难做，点击命中、遮挡、倒计时显示都复杂。
- 美术成本高，每种地貌都要单独处理可种植区域。
- 数值难平衡，因为真实面积和逻辑产量容易混在一起。

### 2.2 推荐方案：不规则地貌区域 + 标准地块槽

地貌区域是视觉和规则容器，地块槽是实际生产单位。

```text
中国农场
  华北旱田区域
    dry_01
    dry_02
    dry_03
  江南水田区域
    paddy_01
    paddy_02
  丘陵茶园区域
    hill_01
    hill_02
```

界面上看到的是一片不规则旱田、一片水田、一片丘陵茶园；玩家点击进去后，里面是几个清晰的地块槽。地块槽可以做成等距小田块、圆形果树坑、莲塘格、温室育苗台，但逻辑上都使用统一的 `PlotSlot`。

### 2.3 地块槽数量

每个地貌区域根据玩法价值配置容量。

| 地貌类型 | 初始槽数 | 满级槽数 | 设计原因 |
| --- | --- | --- | --- |
| 基础粮田 | 2 | 6-8 | 承担大量日常订单，需要高容量 |
| 水田 / 湿地 | 1-2 | 5-6 | 作物更有特色，容量中等 |
| 菜畦 | 2 | 6 | 高频短周期作物，适合早期爽感 |
| 果园 | 1 | 4 | 果树类作物周期长，单槽价值高 |
| 茶园 / 山地 | 1 | 4 | 偏加工和高价值订单 |
| 沙壤 / 盐碱地 | 1 | 3-4 | 偏变异和特色作物，不宜过多 |
| 高原冷田 | 1 | 3 | 高级作物和稀有变异区 |
| 温室 / 试验棚 | 1 | 4 | 变异、反季节和实验玩法核心 |

早期中国建议只开放 3 个区域、6 个槽：

| 阶段 | 区域 | 地块槽 |
| --- | --- | --- |
| 新手 | 华北旱田 | 2 |
| 新手 | 江南水田 | 2 |
| 新手 | 城郊菜畦 | 2 |

随后按国家声望增加：

| 声望 | 新增内容 |
| --- | --- |
| 中国声望 2 | 华北旱田 +1，城郊菜畦 +1 |
| 中国声望 3 | 解锁丘陵茶园，获得 1 槽 |
| 中国声望 4 | 江南水田 +1，解锁果园 |
| 中国声望 5 | 解锁西北沙壤 |
| 中国声望 6 | 解锁高原冷田 |
| 中国声望 7 | 解锁温室试验棚 |

## 4. 界面展示设计

### 4.1 主路径

手机界面建议使用三层路径：

```text
世界地图 -> 国家农场 -> 地貌详情
```

世界地图：

- 展示已解锁国家和可选国家池。
- 点击中国进入“中国农场”。

国家农场：

- 使用一张竖屏可滚动的风格化地图。
- 不同地貌是不规则区域，有明显颜色、纹理和小图标。
- 未解锁地貌显示为半透明轮廓和解锁条件。
- 已解锁地貌显示槽位数量，例如 `2/4`。

地貌详情：

- 顶部显示地貌名称、环境标签和区域收益。
- 中间显示标准地块槽。
- 底部显示可种作物列表，按适应度排序。

### 4.2 地貌区域的视觉规则

不规则区域只负责美术表达，不直接决定种植面积。

| 地貌 | 视觉形状 | 地块槽样式 |
| --- | --- | --- |
| 旱田 | 大块多边形田垄 | 棕黄色条状田块 |
| 水田 | 弯曲水渠围出的浅水面 | 蓝绿色方田，带田埂 |
| 菜畦 | 小块规整菜床 | 规整矩形苗床 |
| 丘陵梯田 | 阶梯形山坡 | 小型阶梯槽 |
| 果园 | 树冠覆盖的圆形区域 | 树坑或果树槽 |
| 沙壤 | 不规则沙地斑块 | 沙色小圃 |
| 高原冷田 | 碎石和草甸块 | 石边小田 |
| 温室 | 建筑内部格架 | 育苗盆 / 栽培台 |

### 4.3 作物选择界面

作物卡片不只显示“能不能种”，而是显示“种了会怎样”。

每张卡片建议显示：

- 作物图标和名称。
- 适应评级：极佳、适宜、可试种、逆境、极限。
- 预计产量区间，例如 `预计 1-2 个`。
- 预计成熟变化，例如 `成长 +20%`。
- 变异提示，例如 `有低概率耐旱变异`。

不要在低适应时禁用按钮。按钮文案可以从“播种”变为“试种”，让玩家知道这是一个有风险但可能有惊喜的选择。

### 4.4 收获反馈

收获结果需要把普通收益和变异发现分开呈现：

```text
收获：中国水稻 x1
产量：逆境低产
发现：耐旱稻种子线索 x1
```

第一次发现变异时进入图鉴弹窗，之后只在收获面板中轻提示。这样变异是惊喜，不会打断每次操作。

## 5. 地貌属性模型

第一版可以用地貌 ID 直接配置适应系数；第二版再升级为环境属性向量。

### 5.1 第一版：直接适应表

每个作物品种配置对不同地貌的系数。

```json
{
  "cropVariantId": "cn_rice",
  "biomeAffinity": {
    "cn_paddy": 1.20,
    "cn_vegetable_bed": 0.65,
    "cn_dry_plain": 0.35,
    "cn_terrace_hill": 0.55,
    "cn_sandy_saline": 0.18,
    "cn_highland_cold": 0.25
  }
}
```

优点是实现快、可控、方便策划调表。

### 5.2 第二版：环境属性向量

后续地貌和作物变多后，可以引入环境属性：

| 属性 | 范围 | 说明 |
| --- | --- | --- |
| `moisture` | 0-100 | 水分，水田高，沙壤低 |
| `fertility` | 0-100 | 肥力，黑土地高，沙地低 |
| `temperature` | 0-100 | 温度，高原低，岭南高 |
| `sunlight` | 0-100 | 光照，沙壤和高原高 |
| `slope` | 0-100 | 坡度，梯田高，平原低 |
| `salinity` | 0-100 | 盐碱，盐碱地和滩涂高 |
| `control` | 0-100 | 人工可控程度，温室高 |

地貌示例：

```json
{
  "biomeId": "cn_sandy_saline",
  "attrs": {
    "moisture": 18,
    "fertility": 25,
    "temperature": 70,
    "sunlight": 90,
    "slope": 20,
    "salinity": 65,
    "control": 5
  },
  "mutationTags": ["drought", "sun", "saline"]
}
```

作物示例：

```json
{
  "cropVariantId": "cn_rice",
  "idealAttrs": {
    "moisture": 85,
    "fertility": 60,
    "temperature": 65,
    "sunlight": 60,
    "slope": 15,
    "salinity": 5
  },
  "attrWeights": {
    "moisture": 0.35,
    "fertility": 0.18,
    "temperature": 0.18,
    "sunlight": 0.12,
    "slope": 0.07,
    "salinity": 0.10
  }
}
```

### 5.3 环境属性如何影响结果

环境属性不要只生成一个总分，还要拆出“压力来源”。总分用于产量，压力来源用于变异方向和收获提示。

每次种植时计算四类结果：

| 结果 | 来源 | 用途 |
| --- | --- | --- |
| 适应系数 `adaptation` | 作物理想属性和地貌属性的距离 | 影响产量、成长时间、品质 |
| 压力向量 `stressVector` | 哪些属性偏离最严重 | 决定变异方向和 UI 提示 |
| 性状匹配 `traitMatch` | 作物已有性状和地貌标签是否匹配 | 给稳定变异品种加成或惩罚 |
| 变异资格 `mutationEligibility` | 是否允许自然变异 | 控制原种可变异，稳定品种不再自然变异 |

第一版可以用以下规则：

```text
attrDistance = abs(plotAttr - cropIdealAttr) / cropToleranceAttr
attrScore = clamp(1 - attrDistance, 0, 1)
baseAdaptation = sum(attrScore * attrWeight)

tagBonus = matchedTraitBonus - conflictingTraitPenalty
adaptation = clamp(baseAdaptation + tagBonus, 0.05, 1.25)
```

这里的 `cropToleranceAttr` 很关键。它表示作物对某个属性的容忍范围，而不是理想值。例如普通水稻理想水分高，但对干旱容忍很低；耐旱稻理想水分降低，干旱容忍变高，但对过湿容忍变低。

### 5.4 属性的方向性

不是所有属性都应该用简单距离计算，有些属性是方向性影响。

| 属性 | 主要影响 | 方向性规则 |
| --- | --- | --- |
| `moisture` | 产量、成长、旱涝压力 | 低于理想形成干旱压力，高于理想形成涝害压力 |
| `fertility` | 产量上限、肥料收益 | 低肥减产，高肥加产但超过上限收益递减 |
| `temperature` | 成长速度、品质 | 低温慢熟，高温快熟但可能降品质 |
| `sunlight` | 糖分、颜色、干旱压力 | 强光提高甜度和色泽，但会放大缺水惩罚 |
| `slope` | 根系、倒伏、机械化 | 坡度高惩罚高秆作物，奖励深根 / 矮生性状 |
| `salinity` | 盐害压力 | 普通作物只受惩罚，耐盐性状把惩罚转为特色加成 |
| `control` | 稳定性、研究效率 | 不直接高产，主要降低随机波动并提高变异培养成功率 |

方向性示例：

```text
如果 plot.moisture < crop.ideal.moisture:
  droughtStress = (crop.ideal.moisture - plot.moisture) / crop.tolerance.drought

如果 plot.moisture > crop.ideal.moisture:
  waterlogStress = (plot.moisture - crop.ideal.moisture) / crop.tolerance.waterlog
```

这样可以表达“耐旱稻适合旱田，但不适合回到水田”。它不是水稻的纯升级，而是把耐旱能力换成了涝害弱点。

### 5.5 稳定变异的属性迁移

稳定变异品种要继承原作物的大类，但迁移理想环境和容忍度。建议每个变异性状包含四类修改：

| 修改项 | 说明 | 示例：耐旱性状 |
| --- | --- | --- |
| `idealShift` | 改变理想环境 | `moisture -40` |
| `toleranceShift` | 改变容忍范围 | `drought +45`, `waterlog -30` |
| `traitBonus` | 匹配地貌加成 | `dry +0.25`, `sandy +0.18` |
| `traitPenalty` | 冲突地貌惩罚 | `paddy -0.35`, `wet -0.25` |

耐旱稻示例：

```json
{
  "id": "cn_drought_rice",
  "sourceVariantId": "cn_rice",
  "stableMutation": true,
  "naturalMutationEnabled": false,
  "traits": ["drought_tolerant", "dryland_specialist"],
  "idealShift": {
    "moisture": -42,
    "fertility": -5
  },
  "toleranceShift": {
    "drought": 45,
    "waterlog": -30,
    "salinity": 5
  },
  "traitBonus": {
    "dry": 0.25,
    "sandy": 0.18
  },
  "traitPenalty": {
    "paddy": -0.35,
    "wet": -0.25
  },
  "yieldCapByTag": {
    "paddy": 0.65,
    "wet": 0.75
  }
}
```

这条规则保证：

- 普通水稻在水田高产，在旱田低产但可能触发耐旱变异。
- 耐旱稻在旱田稳定，在水田会因涝害和地貌冲突减产。
- 耐旱稻是稳定品种，`naturalMutationEnabled=false`，不会再通过普通收获触发自然变异。
- 后续如果要做二次育种，应走单独的“育种 / 杂交 / 研究项目”，不要混进普通种植掉落。

### 5.6 具名地貌、风土与名产共鸣

地貌名字可以和某个代表作物强相关，例如“波尔多葡萄园”“托斯卡纳葡萄园”“日本雪融水田”。这类地貌不要设计成“只能种代表作物”，否则会削弱试种和变异乐趣。

推荐把每个地貌拆成四层：

| 层级 | 作用 | 示例 |
| --- | --- | --- |
| 基础地貌 | 决定大适应方向 | 丘陵、河谷、水田、旱田、湿地、高原、沙地 |
| 环境属性 | 影响产量、成熟期、品质和变异方向 | 温度、水分、日照、土壤、海拔、风、盐碱、肥力 |
| 风土词缀 | 体现地区特色，给所有作物提供变异条件 | 砾石土、海雾、雪融水、火山灰、石灰土、季风雨 |
| 名产共鸣 | 代表作物或代表作物家族的专属优势 | 葡萄在波尔多触发酒庄系加成，茶叶在雾岭茶园触发茶香加成 |

因此，“波尔多葡萄园”可以种水稻、玉米、白菜、茶树和葡萄。区别在于：

- 所有作物都会受到波尔多的通用风土影响，例如湿润、砾石土、昼夜温差、排水快。
- 葡萄额外触发名产共鸣，例如酒庄品质、陈酿价值、厚皮深色、单宁类变异。
- 非葡萄作物不会获得葡萄专属收益，但可以获得波尔多风土变异，例如砾纹厚叶白菜、海雾甜玉米、深色浓香番茄。

具名地貌的设计规则：

- 允许所有满足国家/解锁/基础地块规则的作物试种。
- 代表作物适应度通常较高，但不是唯一可玩作物。
- 风土词缀对所有作物开放，提供地域化变异方向。
- 名产共鸣只对代表作物、代表作物家族或指定加工线生效。
- 如果两个地貌名字相似，必须通过环境属性、风土词缀和共鸣奖励拉开差异。

波尔多葡萄园与托斯卡纳葡萄园示例：

| 地貌 | 通用风土效果 | 葡萄专属共鸣 | 对其它作物的变异倾向 |
| --- | --- | --- | --- |
| 波尔多葡萄园 | 湿润、砾石土、排水快、昼夜温差 | 厚皮、深色、酒香、单宁、窖藏价值 | 根茎作物易出厚皮/耐湿，果菜易出深色/浓香，谷物易出紧实穗 |
| 托斯卡纳葡萄园 | 干热、丘陵、强日照、石灰土、草本香 | 高糖、草本香、耐旱、阳光色泽 | 谷物易出金穗/耐旱，果菜易出甜香/低水耗，叶菜易出阳脆叶 |

这样两个地貌都适合葡萄，但玩法路线不同：

- 波尔多偏高价值酿造、深色、厚皮、陈香和窖藏订单。
- 托斯卡纳偏日照甜度、耐旱、草本香、鲜食和地中海料理订单。

### 5.7 品类适应、品种适应与跨国本土化

同一作物在不同国家可能有不同品种。适应判断不能只看名字，也不能只看国家，要拆成两层：

| 判断层 | 说明 | 示例 |
| --- | --- | --- |
| 品类适应 | 作物大类是否适合地貌 | 水稻对水田高适应，葡萄对丘陵葡萄园高适应 |
| 品种适应 | 具体国家品种是否适应该地貌的细节环境 | 中国南方籼稻到日本温凉水田，品类适应高，但温度和短夏带来品种压力 |

因此，中国水稻种到日本水稻田应该算“品类适应高”，但不一定等于“品种完全适应”。它不会像种到旱田一样严重减产，但可能出现本土化变异。

跨国水稻示例：

| 种植组合 | 品类适应 | 品种压力 | 主要变异池 |
| --- | --- | --- | --- |
| 中国南方籼稻 -> 日本温凉水田 | 高 | 温度偏低、短夏 | 耐寒、短穗、清香、雪融水风土 |
| 中国东北粳稻 -> 日本温凉水田 | 很高 | 压力较低 | 风土精品、清香、雪泉 |
| 中国水稻 -> 埃及尼罗河湿地 | 中高 | 高温、强日照 | 耐热、高秆、金穗、河谷风土 |
| 中国水稻 -> 干旱旱田 | 低 | 缺水严重 | 耐旱、深根、小穗、矮化 |

变异分两类：

| 类型 | 触发条件 | 体验 |
| --- | --- | --- |
| 胁迫变异 | 作物被种到明显不舒服的环境 | 低产、高风险，但可能获得耐旱、耐寒、耐盐、矮化、厚皮等性状 |
| 风土变异 | 作物本来能生长，但长期适应当地特色 | 产量稳定，变异概率较低，但更容易产出地域精品，例如雪泉稻、海雾葡萄、火山番茄 |

这条规则可以同时支撑“国家品种差异”和“同类地貌跨国适应”。玩家不会觉得中国水稻不能种到日本水田很奇怪，也不会觉得跨国种植完全没有新内容。

## 6. 适应系数设计

### 6.1 评级

| 适应系数 | 评级 | 产量 | 成熟时间 | 品质 | 变异概率 |
| --- | --- | --- | --- | --- | --- |
| `1.15+` | 极佳 | 高产 | 正常或略快 | 高品质概率上升 | 极低 |
| `0.90-1.14` | 适宜 | 正常 | 正常 | 正常 | 低 |
| `0.55-0.89` | 可试种 | 略低 | 略慢 | 普通为主 | 中低 |
| `0.25-0.54` | 逆境 | 明显低产 | 变慢 | 低品质概率上升 | 中高 |
| `0.05-0.24` | 极限 | 保底低产 | 明显变慢 | 多为低品质 | 高，但产出少 |

### 6.2 产量公式

建议第一版公式：

```text
stress = max(0, 1 - adaptation)
yieldMultiplier = clamp(adaptation, 0.12, 1.35)
growthMultiplier = 1 + stress * 0.60
qualityPenalty = stress * 0.35

rawYield = baseYield * yieldMultiplier * random(0.85, 1.15)
finalYield = max(1, round(rawYield))
```

关键点：

- 低适应不归零，至少给 1 个产物，保证玩家不会觉得一次尝试完全浪费。
- 低适应会拉长成熟时间，让逆境试种有成本。
- 高适应上限不要太夸张，避免玩家只刷一个最优地貌。

### 6.3 变异概率公式

建议第一版：

```text
stress = max(0, 1 - adaptation)
baseMutationChance = crop.baseMutationChance
stressBonus = stress * stress * 0.08
biomeBonus = plot.biomeMutationBonus
toolBonus = player.researchBonus

mutationChance = clamp(baseMutationChance + stressBonus + biomeBonus + toolBonus, 0, 0.12)
```

默认值：

```text
baseMutationChance = 0.002
普通地貌 biomeMutationBonus = 0
温室 / 试验棚 biomeMutationBonus = 0.01
极限逆境最高不超过 12%
```

这会形成清晰体验：

- 正常种植稳定高产，但几乎不变异。
- 逆境试种低产，但更容易出变异线索。
- 温室和科研建筑可以提高变异效率，但需要中后期解锁。

### 6.4 水稻种到旱田示例

中国水稻基础数据：

```text
推荐地貌：江南水田
baseYield = 4
baseGrowth = 5 分钟
baseMutationChance = 0.2%
```

种到华北旱田：

```text
adaptation = 0.35
stress = 0.65
yieldMultiplier = 0.35
growthMultiplier = 1.39
mutationChance = 0.002 + 0.65 * 0.65 * 0.08 = 3.58%
```

结果体验：

```text
正常情况：收获 1 个低品质水稻
小概率：发现“耐旱稻种子线索”
成熟时间：约 7 分钟
```

玩家知道这不是高效赚钱方式，但会愿意为了图鉴和特殊订单尝试。

## 7. 变异系统

### 7.1 变异不是直接替换作物

收获时触发变异，不建议直接把产物变成新品种。更稳的流程：

1. 玩家逆境试种。
2. 收获时小概率获得 `mutationClue` 或 `unstableSeed`。
3. 在温室或研究棚中鉴定。
4. 解锁“不稳定变异种子”。
5. 在指定地貌连续成功种植若干次后，稳定为正式 `CropVariant`。
6. 正式变异品种进入图鉴，可用于订单和量产。

这样可以避免一次随机就永久解锁太多内容，也给后续建筑和任务系统留空间。

### 7.2 通用地貌变异模板

先做通用模板，再为重点作物做特殊规则。

| 触发地貌 / 标签 | 通用变异标签 | 命名风格 | 玩法效果 |
| --- | --- | --- | --- |
| 旱田、沙壤 | 耐旱 / 沙生 | 耐旱稻、沙纹白菜、旱香麦 | 提高干燥地貌适应，降低水田适应 |
| 水田、湿地 | 喜水 / 浮叶 / 水心 | 浮叶稻、水心白菜、湿生麦 | 提高湿润地貌适应，产量稳定但成长略慢 |
| 盐碱地、沿海滩涂 | 盐晶 / 海风 | 盐晶番茄、海风稻、盐皮瓜 | 适应盐碱，适合特殊订单 |
| 高原、寒地 | 霜芽 / 雪穗 / 紫脉 | 雪穗稻、霜心白菜、紫脉土豆 | 成长慢，售价和品质高 |
| 热带、强日照 | 烈阳 / 蜜熟 | 烈阳玉米、蜜熟番茄、金皮瓜 | 成长较快，售价高，稳定性略低 |
| 丘陵、梯田 | 矮生 / 深根 / 云梯 | 云梯稻、矮秆玉米、岩根萝卜 | 提高坡地适应，抗逆稳定 |
| 黑土地、高肥地 | 巨实 / 厚叶 | 巨穗麦、厚叶白菜、黑土甜玉米 | 高产，成长略慢，肥料收益更高 |
| 茶园、林荫地 | 阴生 / 林香 | 林香姜、阴生白菜、雾叶茶 | 加工香气加成，适合茶饮和料理 |
| 温室、试验棚 | 四季 / 彩化 / 稳定 | 四季稻、彩叶白菜、虹皮番茄 | 适应面广，但国家声望收益较低 |

### 7.3 通用模板的数据结构

```json
{
  "templateId": "drought_common",
  "triggerTags": ["drought", "dry"],
  "cropCategories": ["grain", "leaf", "root", "fruit"],
  "namePrefix": "耐旱",
  "affinityShift": {
    "dry": 0.45,
    "sandy": 0.35,
    "paddy": -0.30
  },
  "yieldShift": -0.05,
  "growthShift": 0.10,
  "mutationRarity": "common"
}
```

通用模板生成的是“可配置新品种”，不是纯随机字符串。策划仍然要审核进入正式图鉴的名字和图标。

### 7.4 重点作物特殊变异

后期为重要作物做特殊变异线，优先选玩家高频接触和有文化识别度的作物。

| 作物 | 触发地貌 | 特殊变异 | 玩法定位 |
| --- | --- | --- | --- |
| 水稻 | 旱田 / 沙壤 | 耐旱稻 | 低水分地貌可稳定量产，产量中等 |
| 水稻 | 湿地 / 莲塘 | 浮叶稻 | 水域收益高，可触发双季订单 |
| 水稻 | 高原冷田 | 雪穗稻 | 成长慢，品质高，稀有料理材料 |
| 水稻 | 盐碱地 | 盐潮稻 | 沿海和盐碱地特色订单 |
| 白菜 | 高原冷田 | 霜心白菜 | 高品质蔬菜，冬季订单核心 |
| 白菜 | 沙壤 | 沙包白菜 | 成长慢但耐旱，外观圆厚 |
| 白菜 | 水田 | 水心白菜 | 产量低但加工汤品加成 |
| 玉米 | 黑土地 | 黑土甜玉米 | 高产甜味，饲料和食品双线 |
| 玉米 | 丘陵梯田 | 矮秆玉米 | 坡地适应，抗风订单 |
| 茶叶 | 丘陵梯田 | 雾岭茶 | 茶饮基础高级线 |
| 茶叶 | 高原冷田 | 雪芽茶 | 稀有高价，成长很慢 |
| 辣椒 | 沙壤 / 强日照 | 烈阳椒 | 辣味订单和料理加成 |

### 7.5 变异稳定规则

变异要有发现、培养、稳定三个阶段。

| 阶段 | 状态 | 玩家行为 | 结果 |
| --- | --- | --- | --- |
| 发现 | 线索 | 逆境收获获得 | 图鉴出现问号条目 |
| 培养 | 不稳定种子 | 在温室或目标地貌种植 | 可能失败、普通产出或继续线索 |
| 稳定 | 正式品种 | 连续成功培养 3 次或消耗研究材料 | 解锁可购买种子 |

稳定后的变异品种仍然有地貌偏好。例如 `耐旱稻` 可以在旱田高适应，但在水田不一定比普通水稻好。

稳定变异品种默认关闭自然变异：

```text
sourceVariant = cn_rice
mutationResult = cn_drought_rice
cn_rice 在旱田可以继续触发耐旱稻线索
cn_drought_rice 在水田只按环境惩罚减产，不触发新的自然变异
```

二次变化必须放到更高阶系统，例如“育种实验”“杂交温室”“国家研究任务”。普通播种和收获只允许原始品种或少数未稳定品种触发自然变异，避免玩家用一个稳定变异品种无限套娃刷图鉴。

### 7.6 二次育种与组合变异系统

稳定变异品种的后续成长走“二次育种”，而不是继续在普通地块里自然变异。

核心循环：

```text
普通作物 -> 地貌试种 -> 一级变异线索 -> 不稳定种子 -> 稳定变异品种
稳定变异品种 A + 稳定变异品种 B -> 育种项目 -> 组合新品种
组合新品种 -> 图鉴收集 / 量产 / 特殊订单 / 继续作为高级育种素材
```

二次育种的入口条件：

| 条件 | 说明 |
| --- | --- |
| 育种设施 | 必须在温室、育种棚、研究所等设施中进行 |
| 稳定亲本 | 亲本必须是已稳定品种，不能直接用线索或不稳定种子 |
| 兼容关系 | 同物种最容易成功，同作物家族可以做高级跨系育种 |
| 目标环境 | 育种项目可以指定目标地貌或环境属性，影响组合方向 |
| 研究材料 | 稀有组合需要消耗风土样本、地区订单奖励或研究点 |

二次育种不是简单把标签相加。内部可以使用标签计算，但对外必须产出一个经过整理的品种：

| 内部数据 | 对外表现 |
| --- | --- |
| `speciesId = rice` | 仍然归入水稻物种图鉴 |
| `traits = drought_tolerant, frostheart, sweet_aroma` | 详情页显示耐旱、霜心、甜香标签 |
| `displayName = 霜旱清香稻` | 作物列表和订单中显示正式品种名 |
| `lineage = 耐旱稻 x 霜心稻` | 图鉴中显示谱系来源 |
| `visualTraits = frost_edge, golden_compact_stalk, pale_grain_core` | 素材只表现 2-3 个主视觉特征 |

命名建议：

- 内部保留完整性状标签，方便数值和组合规则计算。
- 对外品种名最多体现 1-3 个核心特征，避免名字过长。
- 属性详情用标签显示，标签服务说明和筛选，不直接替代品种名。
- 稀有组合可以有专属名字，不必机械使用“名字 + 标签”。

命名示例：

| 内部性状 | 推荐品种名 | 详情标签 |
| --- | --- | --- |
| `drought_tolerant` | 耐旱稻 | 耐旱 |
| `frostheart` | 霜心稻 | 霜心 |
| `drought_tolerant + frostheart` | 霜旱稻 | 耐旱、霜心 |
| `drought_tolerant + frostheart + sweet_aroma` | 霜旱清香稻 | 耐旱、霜心、甜香 |
| `saline + thick_skin + ocean_wind` | 海盐厚皮番茄 | 耐盐、厚皮、海风 |

#### 7.6.1 变异属性分层

第一版不要设计过多属性，先分成五大类，每类逐步扩展。

| 属性类 | 示例 | 主要作用 |
| --- | --- | --- |
| 环境适应 | 耐旱、耐寒、耐热、耐盐、耐湿、耐高原 | 改变地貌适应，形成跨区域策略 |
| 形态变化 | 巨大化、矮化、厚皮、圆硕、深根、密穗 | 改变产量、外观、地块表现和抗逆能力 |
| 品质风味 | 甜、清香、辛香、油润、糯性、脆嫩 | 提高售价、订单价值和加工产物品质 |
| 色彩纹理 | 霜心、金纹、紫化、白化、红芯、星斑 | 提供收集识别和稀有感 |
| 生长节奏 | 早熟、晚熟、多季、夜生、雨生、休眠 | 改变成熟期、离线节奏和种植安排 |

这五类承担不同职责：

- 环境适应负责玩法底盘。
- 形态变化负责模型和产量差异。
- 品质风味负责经济收益和加工系统。
- 色彩纹理负责图鉴收集和视觉记忆。
- 生长节奏负责时间策略。

#### 7.6.2 组合惊喜规则

组合效果必须按作物家族解释，不能所有作物套同一个结果。

| 性状组合 | 谷物类 | 果菜 / 水果类 | 根茎类 | 叶菜类 | 菌类 |
| --- | --- | --- | --- | --- | --- |
| 耐旱 + 甜 | 籽粒更饱满，低水耗，名字偏“旱香”“金穗” | 糖分浓缩，果皮略厚，名字偏“阳蜜”“浓甜” | 根部含糖提高，颜色更深，名字偏“蜜根”“糖芯” | 叶片更脆、更厚，名字偏“甜脆叶” | 香气提升，名字偏“甘香菇” |
| 霜心 + 巨大化 | 大穗、冷光籽粒，成熟期变长 | 果肉半透明，外皮有霜斑，适合甜品加工 | 内芯冰蓝纹理，体型变胖，单个价值高 | 叶脉白蓝，叶球更紧实 | 菌盖带冷色环纹，品质高但产量低 |
| 耐盐 + 厚皮 | 穗壳硬，抗盐碱，产量稳定 | 果皮有盐晶点，适合腌制和海风订单 | 外皮硬，保存期长 | 叶缘硬挺，口感偏脆 | 表面矿物斑，适合药膳订单 |
| 阴生 + 清香 | 穗色低饱和，适合茶点加工 | 香气柔和，甜度不高但售价稳定 | 根部香气提升，产量普通 | 叶片细长，料理品质高 | 菌香明显，特殊料理价值高 |
| 早熟 + 高产 | 快速产出但品质上限低 | 果实偏小、数量多 | 根部小而多 | 叶片密集但品质普通 | 短周期批量订单 |

这样“同一组属性”会在不同作物家族上形成不同惊喜。比如“巨大化”对胡萝卜是胖根，对水稻是大穗，对白菜是紧实叶球，对蘑菇是大菌盖。

#### 7.6.3 组合规则优先级

当一个品种拥有多个性状时，按以下优先级决定实际效果：

| 优先级 | 规则 | 说明 |
| --- | --- | --- |
| 1 | 专属组合规则 | 例如水稻的“霜心 + 耐旱”可以触发“霜旱稻” |
| 2 | 作物家族组合规则 | 例如谷物类的“耐旱 + 甜”转成“旱香金穗” |
| 3 | 通用性状叠加 | 没有特殊组合时，按标签加成和惩罚计算 |
| 4 | 冲突规则 | 互相矛盾的性状触发折中、失败或特殊副作用 |

冲突不要只做失败，也可以做有趣结果：

| 冲突性状 | 普通结果 | 稀有结果 |
| --- | --- | --- |
| 耐旱 + 喜水 | 适应面变宽但产量上限下降 | 双栖稻、潮旱番茄 |
| 早熟 + 晚熟 | 成熟时间回到普通水平，品质波动 | 双季作物，第一次低产、第二次高质 |
| 巨大化 + 矮化 | 体型普通但密度提高 | 矮胖胡萝卜、紧球白菜 |
| 高糖 + 耐盐 | 甜度下降，保存期提高 | 海盐甜瓜、盐蜜番茄 |

#### 7.6.4 多属性视觉表达

多属性品种不能把所有特征都堆到模型上，否则会显得脏。建议每个品种只选择最多 3 个视觉特征：

```text
主视觉性状 60%
副视觉性状 30%
稀有度或品质点缀 10%
```

视觉选择规则：

- 环境适应优先影响整体形态，例如矮、厚、紧、直立、宽叶。
- 色彩纹理优先影响大色块，例如霜边、红芯、金纹、紫脉。
- 品质风味只做局部点缀，例如糖纹、香气光点、油润高光，不大面积改变轮廓。
- 生长节奏通常不直接改变成熟外观，更多体现在动画、成熟提示和 UI 标记。
- 如果性状太多，详情页显示完整标签，地块模型只表现最强的 2-3 个。

视觉示例：

| 品种 | 主视觉 | 副视觉 | 点缀 |
| --- | --- | --- | --- |
| 霜旱清香稻 | 更矮、更紧实、金色干边 | 穗尖霜白、叶脉微蓝 | 少量清香高光 |
| 海盐厚皮番茄 | 果皮更厚更亮、颜色偏深 | 白色盐晶点 | 海风银边 |
| 矮胖蜜根胡萝卜 | 主体更短更胖 | 橙黄色糖芯渐变 | 柔和甜味高光 |
| 雾香茶 | 叶片细长、姿态柔 | 雾白叶缘 | 低饱和清香光点 |

### 7.7 变异素材表现设计

变异品种必须在外观上能被玩家一眼区分，但不能变到看不出母作物。建议采用“三层视觉语法”：

```text
母作物轮廓 70%
变异地貌特征 20%
稀有度 / 品质特效 10%
```

也就是说，`耐旱稻` 仍然首先要像水稻，`霜心白菜` 仍然首先要像白菜；变异特征通过叶形、颜色、纹理、局部器官和少量环境痕迹表达。

#### 7.7.1 素材表现原则

| 原则 | 说明 |
| --- | --- |
| 保留轮廓 | 作物的主轮廓、果实位置、叶片结构要保留，否则图鉴认知会断 |
| 一个主变化 | 小图标里只强调一个最明显变化，例如白霜、盐晶、厚叶、短秆 |
| 不画整片环境 | 素材是透明背景作物，不把地块、天空、水面画进 PNG |
| 可以带少量根部痕迹 | 允许一点沙尘、水珠、盐晶、霜边、碎石贴在作物上，但不要形成背景 |
| 稳定品种更整洁 | 线索和不稳定种子可以怪异，稳定品种要适合长期量产和 UI 复用 |
| 小尺寸优先 | 64dp 图标也要能看出差异，细节只在图鉴大图里补充 |

#### 7.7.2 通用变异视觉模板

| 变异方向 | 通用视觉特点 | 颜色倾向 | 形态倾向 | 纹理 / 局部特征 |
| --- | --- | --- | --- | --- |
| 耐旱 / 沙生 | 干燥、紧凑、抗逆 | 黄绿、浅金、沙褐边缘 | 叶片更窄更厚，尖端略卷，植株更矮 | 叶缘干纹、蜡质高光、根部少量沙尘 |
| 喜水 / 浮叶 / 水心 | 饱水、清透、柔软 | 青绿、浅蓝绿、半透明白 | 叶片更宽，姿态舒展，茎更长 | 水珠、水纹脉络、局部半透明质感 |
| 盐晶 / 海风 | 盐碱、海风、矿物感 | 灰绿、银白、淡青 | 叶缘略硬，果皮或叶面更厚 | 白色盐晶点、银色边线、浅色结晶斑 |
| 霜芽 / 雪穗 / 紫脉 | 高寒、慢生、高品质 | 冷绿、霜白、淡蓝、紫脉 | 植株更紧实，叶心或穗尖收拢 | 霜边、冰晶点、紫色叶脉、白色尖端 |
| 烈阳 / 蜜熟 | 强光、糖分、热带 | 金黄、橙红、亮绿 | 果实更饱满，叶片略上扬 | 日晒斑、糖纹、暖色高光、微卷叶缘 |
| 矮生 / 深根 / 云梯 | 坡地、抗风、扎根 | 深绿、土褐、岩灰 | 茎更短更粗，根部存在感更强 | 粗根、石纹、节间更密、低重心 |
| 巨实 / 厚叶 | 高肥、高产、饱满 | 深绿、墨绿、乳白、丰收金 | 果实或叶球更大，叶片更厚 | 厚叶褶皱、饱满高光、黑土色根部 |
| 阴生 / 林香 / 雾叶 | 林荫、香气、柔和 | 暗绿、青灰、淡雾白 | 叶片更细长，姿态更柔 | 雾状浅边、细叶脉、低饱和高光 |
| 四季 / 彩化 / 稳定 | 温室、人工选择、稳定 | 干净高饱和，可有双色点缀 | 对称、整洁、缺陷少 | 均匀纹理、彩色叶脉、小面积亮色变异 |

#### 7.7.3 阶段表现

变异品种在不同阶段的视觉强度不同：

| 阶段 | 图标表现 | 地块表现 |
| --- | --- | --- |
| 线索 | 不显示完整作物，只显示种子、碎叶、问号轮廓 | 收获弹窗出现线索物品 |
| 不稳定种子 | 外观有明显异常，但形态不完全规整 | 地块上可轻微抖动、颜色不均 |
| 稳定品种 | 完整独立素材，轮廓清楚，变异特征稳定 | 正常种植、成熟、收获动画 |
| 稀有稳定品种 | 在稳定品种基础上增加少量品质高光 | 图鉴大图和订单卡上更精致，地块小图不过度发光 |

不稳定阶段可以更夸张，稳定阶段必须收敛。玩家长期看的地块素材要干净，避免视觉疲劳。

#### 7.7.4 重点作物视觉示例

| 作物 | 变异品种 | 外观设计 |
| --- | --- | --- |
| 水稻 | 耐旱稻 | 植株更矮，叶片窄厚，穗色偏金，根部有少量沙尘，整体比普通水稻更直立 |
| 水稻 | 浮叶稻 | 茎更长，底部有少量浮叶形态，叶片更宽更青，穗粒较少但更亮 |
| 水稻 | 雪穗稻 | 稻穗尖端带霜白，叶片冷绿，叶脉微蓝紫，整体更紧实 |
| 水稻 | 盐潮稻 | 叶缘银白，穗壳有细盐晶点，颜色偏灰绿，质感更硬 |
| 白菜 | 霜心白菜 | 白色菜心更亮，外叶边缘有浅蓝霜边，叶球紧实 |
| 白菜 | 沙包白菜 | 叶球更圆更矮，外叶厚，边缘有沙褐纹，整体像紧包的耐旱菜球 |
| 白菜 | 水心白菜 | 叶片更浅、更透，菜心偏水白，叶脉带细水珠 |
| 白菜 | 彩叶白菜 | 保持白菜轮廓，叶脉出现小面积粉紫或金黄彩化，不做大面积花哨配色 |
| 玉米 | 黑土甜玉米 | 玉米棒更饱满，叶片深绿，根部带黑土色，玉米粒偏金亮 |

| 茶叶 | 雾岭茶 | 茶叶细长，边缘有雾白浅边，颜色低饱和，整体更清雅 |
| 茶叶 | 雪芽茶 | 嫩芽更白，尖端带霜晶，叶片偏冷绿，数量少但品质感强 |
| 辣椒 | 烈阳椒 | 辣椒颜色更红橙，表皮有金色日晒斑，柄叶更亮绿 |

#### 7.7.5 界面中的变异识别

同一个变异品种在不同界面使用不同信息密度：

| 界面 | 表现方式 |
| --- | --- |
| 地块小图 | 只显示作物主体和一个最强变异特征 |
| 作物选择卡 | 作物图标 + 变异标签色条 + 适应评级 |
| 图鉴 | 大图 + 母作物关系 + 触发地貌 + 性状说明 |
| 订单 | 图标旁显示国家 / 地貌来源徽标，避免同物种混淆 |
| 收获弹窗 | 普通产物和变异线索分开展示 |

视觉上不要只靠文字区分。即使去掉名字，玩家也应该大致看出这是“普通水稻”“耐旱稻”还是“雪穗稻”。

#### 7.7.6 素材生产规则

素材可以分两档制作：

| 档位 | 使用场景 | 制作方式 |
| --- | --- | --- |
| 通用变异 | 大量作物的早期内容 | 使用通用视觉模板生成完整透明 PNG |
| 特殊变异 | 重点作物、活动作物、付费或长期目标 | 单独设计完整 PNG，必要时增加成熟阶段差异 |

第一版不建议做复杂图层合成。每个稳定品种直接产出一张透明 PNG，命名规则：

```text
crop_{speciesId}_{variantId}.png
crop_rice_cn_drought.png
crop_cabbage_cn_frostheart.png
```

后续如果作物数量变多，再考虑：

- 基础作物主体图。
- 通用变异覆盖层，例如霜边、盐晶、沙尘。
- 图鉴大图使用完整独立素材。
- 地块小图使用合成图或预烘焙图。

#### 7.7.7 图片生成提示词模板

生成变异素材时，提示词应由“母作物 + 变异模板 + 约束”组成：

```text
single {cropName} crop game asset, transparent background,
keep the recognizable silhouette of {baseCropName},
apply {mutationVisualTemplate}: {visualDetails},
2D mobile farming game style, clean crisp edges,
centered full plant, readable at small icon size,
no soil patch, no full background, no text, no border, no watermark
```

耐旱稻示例：

```text
single rice plant crop game asset, transparent background,
keep the recognizable silhouette of rice,
drought-tolerant dryland mutation: shorter upright stalks, narrow thick waxy leaves, golden dry leaf edges, small sandy dust near roots,
2D mobile farming game style, clean crisp edges,
centered full plant, readable at small icon size,
no soil patch, no full background, no text, no border, no watermark
```

## 9. 开发顺序建议

### M1：固定适应表

- 只做中国 3 个地貌：华北旱田、江南水田、城郊菜畦。
- 每个地貌 2 个地块槽。
- 每个作物配置 `biomeAffinity`。
- UI 显示适应评级和预计产量。

### M2：逆境试种

- 所有已解锁中国作物允许种在中国任意已解锁地貌。
- 低适应降低产量、增加成熟时间。
- 收获时显示“适应结果”。

### M3：通用变异

- 加入通用变异模板：耐旱、喜水、霜芽、厚叶。
- 收获时小概率掉落变异线索。
- 图鉴支持问号变异条目。

### M4：温室稳定

- 解锁温室试验棚。
- 变异线索可以转为不稳定种子。
- 完成培养后解锁正式变异品种。

### M5：特殊变异线

- 为水稻、白菜、玉米、茶叶各做 2-4 个特殊变异。
- 引入国家和地貌特色订单。
- 让跨国作物也有不同国家的变异分支。

### M6：二次育种和组合变异

- 解锁育种设施，允许稳定变异品种作为亲本。
- 先只支持同物种育种，例如水稻 x 水稻、白菜 x 白菜。
- 加入 5-10 条作物家族组合规则，例如谷物类“耐旱 + 甜”、根茎类“巨大化 + 甜”。
- 图鉴显示品种谱系、核心性状、触发地貌和育种来源。
- 多属性品种使用正式品种名 + 标签详情，不直接把所有标签堆在列表名里。

## 10. 关键规则

- 地貌负责“地域感”和“环境规则”，地块槽负责“实际种植操作”。
- 具名地貌不是只能种代表作物；它通过风土词缀影响所有作物，通过名产共鸣强化代表作物。
- 不要让地貌直接变成唯一地块；每个地貌至少 2 个槽，稀有地貌也应有扩展空间。
- 品类适应和品种适应分开判断；同类地貌跨国种植通常不应严重惩罚，而应偏向本土化风土变异。
- 低适应不失败，低产保底，保留试错意愿。
- 变异概率随逆境提高，但要有上限，避免玩家只刷极限环境。
- 通用变异解决内容量问题，特殊变异负责记忆点和传播点。
- 变异品种必须重新绑定地貌适应，不应该成为全地貌最优答案。
- 稳定变异品种必须有代价；适应逆境后，回到原高适应地貌应因性状冲突减产。
- 稳定变异品种默认不再自然变异；二次变化只能放到独立育种系统。
- 二次育种内部使用性状标签计算，对外产出正式品种名、谱系记录和少量核心视觉特征。
- 性状组合效果必须按作物家族或具体作物解释，避免所有作物共享同一套组合结果。
- 变异素材必须保留母作物轮廓，用通用视觉模板表达地貌性状，不能只靠名字区分。
