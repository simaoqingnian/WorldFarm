# 普通胡萝卜 v001 轮廓规格

本文件用于把“感觉”转成可建模的控制点。确认后，Blender 灰模按这些点建。

## 坐标约定

- `Y = 0%` 表示胡萝卜最底部。
- `Y = 100%` 表示胡萝卜橙色主体和叶簇连接处。
- 半径使用相对最大半径的比例。
- 正式建模时先按正面轮廓创建，再检查侧面厚度。

## 已确认方向

| 决策项 | 用户选择 | 建模解释 |
| --- | --- | --- |
| 整体大形比例 | `1.A` | 短胖型，高度约为最大宽度的 `2.2` 倍 |
| 顶部叶簇处理 | `2.C` | 橙色顶部主体明显可见，叶子从中间长出 |
| 主体侧面轮廓 | `3.B` | 主体笔直对称，不做明显弯曲 |
| 表面规则度 | `4.B` | 允许极轻微自然不对称，但不能出现横向环线 |
| 第一版范围 | `5.A` | 只做成熟单根胡萝卜 |

## 当前控制点

| 控制点 | 高度 | 半径 | 当前建议 | 状态 |
| --- | ---: | ---: | --- | --- |
| P0 底部钝头 | 0% | 26% | 更窄、更圆润，不尖，不做底部平边 | `locked` |
| P1 下身过渡 | 18% | 42% | 从底部平滑变宽，不先收缩再鼓起 | `locked` |
| P2 中段过渡 | 42% | 62% | 不是最宽点，只承担倒圆锥中段过渡 | `locked` |
| P3 上身过渡 | 68% | 82% | 继续向顶部平滑变宽 | `locked` |
| P4 最宽肩部 | 90% | 100% | 最宽点在顶部附近，形成平滑倒圆锥 | `locked` |
| P5 顶部发叶口 | 100% | 72% | 顶部橙色明显可见，叶子从中心直立长出 | `locked` |

## 轮廓规则

- P0 到 P4 必须整体单调变宽，接近平滑倒圆锥。
- P0 到 P1 不能出现先收缩再外鼓的腰线。
- P2 不是最宽点，P4 附近才是最宽点。
- P4 到 P5 是顶部圆肩收口，不能出现平台、碗沿或突然折线。
- 顶部橙色主体可以明显可见，但必须是圆润肩颈，不能形成可见碗口。
- 叶簇从 P5 中央直立长出，不依赖覆盖顶部来掩盖错误。
- 叶簇使用 5 到 7 根卡通圆润叶茎，先从中心向上，再轻微向四周发散。
- 当前版本不使用扁平叶片轮廓。
- 中段不能出现横向凸环。
- 底部一旦用户确认通过，标记为 `locked`。

## 第一版建议比例

| 参数 | 建议值 | 说明 |
| --- | ---: | --- |
| 高度/最大宽度 | 2.2 | 保持短胖，但形状改为上宽下窄 |
| 最大宽度位置 | 90% | 最宽点移动到 P4 附近 |
| 顶部肩部宽度 | 100% | P4 附近最宽，形成倒圆锥主体 |
| 顶部发叶口宽度 | 72% | 顶部不再过窄，叶子从中心直立长出 |
| 中段宽度 | 62% | P2 只做中段过渡，不作为肚子 |
| 底部宽度 | 26% | 比上一版更窄、更圆润，P0/P1 之间不做收缩曲线 |
| 侧面厚度 | 正面宽度的 88% | 避免完全圆柱感 |
| 主体轴线 | 0% 弯曲 | 正面和侧面保持笔直对称 |
| 表面不对称 | 2% - 4% | 只用于后续细节，轮廓阶段暂不启用 |

## 已确认问题

1. 接受“短胖萝卜形”，高度约为最大宽度的 2.2 倍。
2. 顶部橙色主体明显可见，叶子从中间长出。
3. 主体保持完全笔直对称。
4. 表面允许极轻微自然不对称，但不能出现横向环线。
5. 第一版只做成熟单根胡萝卜，不做幼苗、半熟和变异。

## 阶段 2 第一轮反馈修订

日期：2026-08-31

用户反馈：

- 胡萝卜顶部太窄。
- 叶子像覆盖在胡萝卜顶端，应该从顶端直立长出。
- P2 不应该是最宽点，最宽点应在 P4 附近。
- 形状接近倒圆锥，但需要平滑一点。
- 底部 P0 和 P1 不要有收缩曲线。

修订结果：

- 顶部发叶口从 `28%` 调整到 `72%`。
- 最宽点从 P2 调整到 P4。
- P2 改为中段过渡点，不再命名为最大肚子。
- P0/P1 改成平滑单调变宽，避免底部收缩腰线。
- 叶簇方向改为从顶部中心直立发散，不再覆盖橙色顶部。

## 阶段 2 第二轮反馈修订

日期：2026-08-31

用户反馈：

- 胡萝卜主体顶部形状通过。
- 主体通过。
- 最宽点通过。
- 叶子太小，需要从中心直立长出，再向四周扩散。
- 底部太平，需要再窄一点、圆润一点。

修订结果：

- 顶部橙色主体、主体倒圆锥趋势和 P4 最宽点标记为本轮通过方向，后续不主动改。
- 叶簇放大，并改为先从顶部中心向上生长，再向四周发散。
- P0 底部半径从 `34%` 调整到 `26%`。
- 底部 SVG 曲线从宽平弧改为更窄的圆弧底。

## 阶段 2 第三轮反馈修订

日期：2026-08-31

用户反馈：

- 底部通过。

修订结果：

- 叶簇从扁平叶片改为 5 到 7 根粗圆头叶茎。
- 叶茎统一从顶部中心出发，先直立向上，再轻微向四周扩散。
- 当前轮廓阶段只验收叶茎造型是否通过。
