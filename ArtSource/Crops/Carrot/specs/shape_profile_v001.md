# 普通胡萝卜 v001 轮廓规格

本文件用于把“感觉”转成可建模的控制点。确认后，Blender 灰模按这些点建。

## 坐标约定

- `Y = 0%` 表示胡萝卜最底部。
- `Y = 100%` 表示胡萝卜橙色主体和叶簇连接处。
- 半径使用相对最大半径的比例。
- 正式建模时先按正面轮廓创建，再检查侧面厚度。

## 初始建议控制点

| 控制点 | 高度 | 半径 | 当前建议 | 状态 |
| --- | ---: | ---: | --- | --- |
| P0 底部钝头 | 0% | 28% | 圆润，不尖 | `proposed` |
| P1 下身鼓起 | 18% | 58% | 从底部快速外鼓 | `proposed` |
| P2 最大肚子 | 42% | 100% | 最大宽度偏下，短胖 | `proposed` |
| P3 上肩 | 68% | 86% | 平滑收窄，不凹陷 | `proposed` |
| P4 顶部颈口 | 100% | 18% | 小钝颈，被叶冠覆盖 | `proposed` |

## 轮廓规则

- P0 到 P2 必须是外凸弧线。
- P2 到 P4 必须连续收窄，不出现平台、碗沿或突然折线。
- 顶部橙色主体不能形成可见碗口。
- 中段不能出现横向凸环。
- 底部一旦用户确认通过，标记为 `locked`。

## 第一版建议比例

| 参数 | 建议值 | 说明 |
| --- | ---: | --- |
| 高度/最大宽度 | 2.2 | 明显短胖，避免旧版偏高 |
| 最大宽度位置 | 42% | 肚子偏下，更像根茎 |
| 顶部颈口宽度 | 18% | 只作为叶簇根部，不作为碗沿 |
| 底部宽度 | 28% | 钝圆，保留上一轮满意方向 |
| 侧面厚度 | 正面宽度的 88% | 避免完全圆柱感 |
| 轮廓不对称 | 3% - 6% | 轻微自然感，不影响可爱风格 |

## 待确认问题

1. 你是否接受“短胖萝卜形”，高度约为最大宽度的 2.2 倍？
2. 顶部是否允许被绿色叶冠基本盖住，只露出很小橙色颈口？
3. 是否允许胡萝卜主体有轻微自然弯曲，还是必须完全笔直对称？
4. 第一版是否只做成熟单根胡萝卜，不做幼苗、半熟和变异？
