# Carrot Exports

本目录保存从 Blender 导出的游戏资产文件。

建议命名：

- `Crop_Carrot_Normal_v001.fbx`
- `Crop_Carrot_Normal_v001.glb`
- `Crop_Carrot_Normal_v001_blockout.fbx`
- `Crop_Carrot_Normal_v001_model.fbx`

导出规则：

- 单位使用 Unity 兼容比例。
- 轴向以 Unity 导入结果为准。
- 原点放在地面接触点或作物根部中心。
- 导出前应用缩放和旋转。
- 正式导入 Unity 后，对应 prefab 放到 `UnityProject/Assets/WorldFarm/Art/Crops/Carrot/`。
