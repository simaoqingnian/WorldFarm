# 普通胡萝卜 v001 阶段 2 轮廓参考验收

参考文件：

- `carrot_normal_v001_silhouette.svg`

本阶段只看轮廓和控制点，不看贴图、材质、叶脉、表面斑点和 Unity 光照。

## 当前方案

- 大形：短胖，高度约为最大宽度的 `2.2` 倍。
- 顶部：橙色主体明显可见，叶子从中间长出。
- 轴线：正面和侧面保持笔直对称。
- 肚子：最大宽度在 `42%` 高度附近。
- 底部：钝圆，不做尖锥。
- 表面：当前轮廓无横向环线。

## 需要用户验收

请按下面格式反馈：

```text
整体比例：通过 / 太高 / 太胖 / 太瘦
顶部：通过 / 橙色太多 / 橙色太少 / 仍像碗 / 叶子位置不对
肚子：通过 / 最大肚子太靠上 / 太靠下 / 仍有环线感
底部：通过 / 太圆 / 太尖 / 太宽 / 太窄
侧面：通过 / 太厚 / 太薄 / 不够直
是否进入 Blender 灰模：是 / 否
```

如果只想简单确认，可以回复：

```text
阶段 2 通过，进入 Blender 灰模
```
