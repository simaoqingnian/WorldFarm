# 普通胡萝卜 v001 阶段 2 轮廓参考验收

参考文件：

- `carrot_normal_v001_silhouette.svg`

本阶段只看轮廓和控制点，不看贴图、材质、叶脉、表面斑点和 Unity 光照。

## 当前方案

- 大形：短胖，高度约为最大宽度的 `2.2` 倍。
- 顶部：橙色主体明显可见，叶子从中间长出。
- 轴线：正面和侧面保持笔直对称。
- 主体：接近平滑倒圆锥，最宽点在 P4 附近。
- 中段：P2 不是最宽点，只做过渡。
- 叶簇：5 到 7 根卡通圆润叶茎，从顶部中心先直立长出，再轻微向四周扩散。
- 底部：已通过并锁定，不做尖锥和平底。
- 表面：当前轮廓无横向环线。

## 需要用户验收

请按下面格式反馈：

```text
叶簇：通过 / 太少 / 太多 / 太细 / 太粗 / 不够卡通 / 不够直立 / 扩散太多 / 仍像扁叶子
是否进入 Blender 灰模：是 / 否
```

如果只想简单确认，可以回复：

```text
阶段 2 通过，进入 Blender 灰模
```
