# Carrot References

允许放入：

- 用户手绘草图。
- AI 生成概念图。
- 可合法使用的公开参考图链接记录。
- 正面、侧面、俯视轮廓图。

建议命名：

- `carrot_normal_v001_front_ref.png`
- `carrot_normal_v001_side_ref.png`
- `carrot_normal_v001_top_ref.png`
- `carrot_normal_v001_mood_ref.md`

不要提交未确认版权的大图原图。可以在 `mood_ref.md` 中记录链接和观察点。
