# WorldFarm Art Source

本目录保存正式美术源资产，不保存 Unity 自动生成缓存。

## 目录职责

- `Crops/`: 作物源资产。
- `Biomes/`: 地貌、地块和区域环境源资产。
- `Buildings/`: 建筑、设施和装饰源资产。
- `Characters/`: 后续角色或引导员源资产。
- `UI/`: 图标、插画、界面展示图源资产。

## 正式资产流程

1. 写资产需求卡。
2. 收集或生成参考图。
3. 确认正面/侧面轮廓。
4. 建立 Blender 灰模。
5. 输出三视图和 Unity 预览截图。
6. 根据标注反馈修改。
7. 锁定剪影和体块。
8. 添加基础颜色和材质。
9. 导出 `fbx` 或 `glb`。
10. 导入 Unity 并生成 prefab。
11. 在 `AssetPreview` 场景中验收。
12. 构建 Android APK 实机验收。

## 锁定规则

- 用户明确说“通过”或“满意”的局部，记录为 `locked`。
- 除非用户明确要求，不再修改已锁定局部。
- 每轮反馈都写入对应资产的 `feedback.md`。
- 需求卡、规格表、截图和导出文件必须能对应同一个版本号。

## 不进 Git 的内容

- Blender 自动备份文件。
- 大型临时渲染图。
- 构建缓存。
- 未确认使用权的第三方参考素材。

大型正式资产后续建议启用 Git LFS。
