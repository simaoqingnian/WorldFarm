# WorldFarm Unity Project

This is the Unity main project for WorldFarm.

Open this folder with Unity Hub:

```text
D:\03_work\09_android\WorldFarm\UnityProject
```

Current local setup:

- Tuanjie `2022.3.62t14`
- Android Build Support
- Android SDK & NDK Tools
- OpenJDK

The project currently contains the first domain model layer for biome, crop adaptation, plot slots, and mutation rules. Unity Editor will generate `Library/`, `Temp/`, and complete editor settings when the project is opened.

The Android preview build uses `Assets/WorldFarm/Scenes/AssetPreview.unity` and outputs:

```text
D:\03_work\09_android\WorldFarm\Builds\Android\WorldFarm-dev.apk
```
